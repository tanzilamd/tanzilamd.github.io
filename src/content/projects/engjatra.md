## Start from a language you know
EngJatra is a Bangla-first English-learning project for adults. It brings structured practice, reading and vocabulary into an interface designed to make the next step understandable.

The central idea is to use Bangla as a bridge. The project includes authored activities and scripted dialogue, so useful learning material does not depend entirely on an AI conversation.

## A learning product has two sides
The architecture separates the learner experience from the editorial and administrative application. Shared content contracts and UI packages help keep those experiences consistent while their responsibilities remain distinct.

The implementation uses React and TypeScript, with a Cloudflare Worker API and Supabase-backed services. Learning content and progress behavior are substantial parts of the work alongside the visible interface.

## Learning beyond a chat box
- Reading, vocabulary and authored practice.
- A learner-oriented interface with Bangla explanations.
- Separate tools for managing content and operations.
- A project structure that treats learning content as something to maintain and improve.

## An evolving body of work
The repository documents the current implementation, validation and remaining release gates. This is not a claim of certification or a measured learning outcome. The next useful questions concern the quality of the learning experience as much as the software beneath it.
